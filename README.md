# ONG Projeto Social

Projeto acadêmico desenvolvido em HTML5 com foco em estrutura semântica, acessibilidade, organização de conteúdo e validação de formulários.

A proposta foi criar um site institucional para uma ONG, permitindo apresentar projetos sociais, formas de contribuição e um formulário de cadastro para voluntários e colaboradores.

---

## Objetivo

Desenvolver páginas web utilizando boas práticas de HTML5, com atenção à:

- Estrutura semântica
- Hierarquia de títulos
- Acessibilidade
- Organização de diretórios
- Formulários
- Validação de dados
- Uso de imagens em diferentes formatos

---

## Páginas do projeto

### Página inicial

Apresenta a ONG, sua missão e direciona o usuário para os projetos sociais.

Arquivo:

`html/index.html`

### Projetos

Apresenta informações sobre:

- Projetos sociais
- Doações
- Voluntariado
- Campanhas e ações da ONG

Arquivo:

`html/projetos.html`

### Cadastro

Contém o formulário para cadastro de voluntários e colaboradores, incluindo dados pessoais, contato e endereço.

Arquivo:

`html/cadastro.html`
